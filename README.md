# AZA GOLD — نسخه اولیه PWA

این بسته یک نمونه رابط کاربری اولیه برای نرم‌افزار مدیریت طلافروشی است.

## اجرا
- ساده‌ترین روش: از پوشه پروژه یک سرور محلی اجرا کنید.
- با Python: `python -m http.server 8000`
- سپس در مرورگر باز کنید: `http://localhost:8000`
- برای نصب PWA در محیط واقعی، سایت باید از HTTPS ارائه شود (localhost برای توسعه مجاز است).

## امکانات این نسخه
- رابط فارسی و راست‌چین
- طراحی واکنش‌گرا برای موبایل و دسکتاپ
- داشبورد با اطلاعات نمونه
- منوی بخش‌های فروش، انبار، مشتریان، خرید، صندوق، گزارش و تنظیمات
- فرم نمایشی پیش‌فاکتور با جمع تقریبی
- صفحه مشتریان بدهکار با جست‌وجو، مانده بدهی نمونه، دکمه تماس مستقیم (tel:) و خروجی CSV
- manifest و service worker پایه برای shell آفلاین

## مهم
این نسخه فقط فرانت‌اند نمایشی است:
- به سرور یا پایگاه داده وصل نیست.
- اطلاعات فرم‌ها ذخیره نمی‌شوند.
- ارقام داشبورد نمونه‌اند.
- محاسبه مالیات قانونی، صدور صورتحساب رسمی و اتصال سامانه مؤدیان پیاده‌سازی نشده‌اند.
- برای تولید واقعی باید API امن، پایگاه داده، ورود کاربران، ثبت رویدادها، پشتیبان‌گیری، اعتبارسنجی و آزمون‌های محاسباتی اضافه شوند.


## اجرای درست روی موبایل
باز کردن index.html از پیش‌نمایش فایل‌منیجر (آدرس content://) ممکن است CSS، JavaScript و PWA را بارگذاری نکند. فایل ZIP را کامل استخراج کنید و پروژه را روی یک وب‌سرور اجرا کنید؛ برای تست رایانه می‌توان از `python -m http.server 8000` استفاده کرد. برای استفاده از موبایل، پروژه را روی هاست HTTPS منتشر کنید و لینک آن را در Chrome باز کنید.
